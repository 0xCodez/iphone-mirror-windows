# Material Icons Outlined

`iphone_mirror/MaterialIconsOutlined-Regular.otf` is the classic outlined Material Icons font from [google/material-design-icons](https://github.com/google/material-design-icons), used for the window bar and the empty screens.

It is licensed under the Apache License, Version 2.0. You can read the license at <https://www.apache.org/licenses/LICENSE-2.0>.

The font file is the frozen outlined set shipped with this repo. Do not replace it with a newer variable font unless the codepoints used by the window are checked again.
